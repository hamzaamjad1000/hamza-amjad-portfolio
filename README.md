# Getting Started

## Clone Repository

```bash
git clone https://github.com/hamzaamjad1000/hamza-amjad-portfolio.git
```

---

# Frontend Setup

Navigate to frontend:

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

Run the project:

```bash
npm start
```

---

# Backend Setup

Navigate to Django backend:

```bash
cd backend_django
```

Create virtual environment:

```bash
python -m venv venv
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Start development server:

```bash
python manage.py runserver
```
